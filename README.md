# 🐾 발자국 연구소

> **“세상의 모든 댕냥이들이 따뜻한 가족을 만나도록 쓰는 입양 홍보 다이어리”**

---

## 1. 서비스 명
* **서비스 국/영문 명칭**: Pawprint Diary (발자국 연구소)
* **초기 프로토타입 명칭**: 댕냥이 입양 홍보 생성기 (Pet Adoption Story Engine)
* **슬로건**: “AI가 가족을 기다리는 댕냥이의 매력과 사연을 감성적인 스크랩북 다이어리로 편철합니다.”

---

## 2. 서비스 정의
* **정의**: 유기동물 및 입양 대기 동물의 프로필과 사연을 입력하면, AI가 딱딱한 공고문 양식을 벗어나 **“감성 손글씨 스크랩북과 아이 시점의 손편지 다이어리”**로 자동 재구성해 주는 AI 입양 홍보 아카이빙 플랫폼
* **핵심 지향점**: 단순 데이터 전달을 넘어 **“반려동물의 고유한 매력을 다이어리 감성으로 입체화하여 입양 문의와 소셜 바이럴을 극대화하는 콘텐츠 엔진”**

---

## 3. 기획 배경 (문제 인식)
* **딱딱하고 정형화된 공고문**: 보호소 입양 공고는 관리 번호, 체중, 발견 장소 등 단순 행정 데이터 위주로 작성되어 아이의 숨은 애교나 개성을 파악하기 어려움
* **낮은 시각적 몰입도와 공유율**: 텍스트 위주의 평이한 정보는 SNS 피드에서 빠르게 지나쳐져 잠재적 입양자의 시선을 사로잡지 못함
* 🔥 **핵심 문제**: *“아이들은 저마다 특별한 매력과 사연을 품고 있지만, 이를 감성적으로 구조화하여 널리 확산시킬 전문 입양 홍보 도구가 부족한 상황”*

---

## 4. 서비스 발전 과정 (MVP ➔ 최종 Pastel Scrapbook 버전)
실제 UI/UX 피드백과 소셜 연동 확장성을 바탕으로 완성도 높은 스크랩북 시스템을 구축했습니다.

```plaintext
[Phase 1. 초기 MVP : 텍스트 생성기] ────► [Phase 2. 최종 확장 : Pawprint Lab]
· 타깃: 기본 보호소 공고 요약               · 타깃: 유기동물 임시보호자, 보호소 봉사자, 입양 희망자
· 톤앤매너: 평이한 웹 폼 디자인             · 톤앤매너: 파스텔 핑크/라벤더, 폴라로이드 & 마스킹 테이프 다꾸
· 산출물: 마크다운 텍스트                   · 산출물: 프로필 스티커 + 아이 시점 손편지 메모 박스
· 기능: 단순 생성 및 로컬 저장              · 5개 탭: 프로필 다꾸 / 댕냥이 앨범 / 플레이리스트 / 가이드 / 보관함
```

* **초기 프로토타입 단계 (Phase 1 - MVP)**:
  * **핵심 기능**: 동물 이름과 기본 사연을 바탕으로 입양 홍보글을 생성하고 브라우저에 저장
  * **한계점 발견**: 마크다운 기호(`>`, `*`)가 그대로 드러나 스크랩북 무드가 살지 않고, 이모지 인코딩 깨짐 발생
* **최종 고도화 단계 (Phase 2 - Pastel Scrapbook System)**:
  * **다꾸 룩앤필 구축**: Gamja Flower 및 Gaegu 폰트, 파스텔 줄노트 배경, 파스텔 테이프 오브젝트 적용
  * **기능 확장**: 5탭 SPA 구조, 유니코드 안전 정규식 파서, 디스코드 웹훅 즉시 발송, 품종별 유튜브 검색 바로가기, 로컬 영구 보관함 지원

---

## 5. 해결 전략 (3단 구조화)
* **5.1 AI 감성 다이어리 엔진**: 아이의 이름과 성격, 사연을 분석하여 핵심 프로필 스티커와 1인칭 손편지 문안을 자동 결합 추출
* **5.2 스크랩북 지면 구조화**: `[STICKER // NEW PROFILE]` ➔ 프로필 스티커 ➔ 핑크 편지 메모지 박스 ➔ 액션 바(복사 / 디스코드 / 유튜브)로 이어지는 완성형 레이아웃 제공
* **5.3 영구 편철 및 소셜 허브**: 완성된 페이지를 브라우저 로컬 저장소에 고유 페이지 번호(`PAGE #`)로 보관하고, 디스코드 커뮤니티 및 유튜브 채널과 원클릭 연동

---

## 6. 주요 기능 상세 명세
* **6.1 다이어리 페이지 발행 (프로필 다꾸)**: 이름, 품종/나이, 메모 입력 시 비동기 AI 감성 일기장 즉시 생성
* **6.2 5탭 SPA UI 시스템**:
  * `01. ✏️ 프로필 다꾸`: 메인 스토리 생성기
  * `02. 🧸 댕냥이 앨범`: 대표 보호 동물 퀵필(QuickFill) 앨범 (구름이, 모찌 등)
  * `03. 🎧 뽀짝 플레이리스트`: 작업 시 감상 가능한 힐링 사운드 트랙
  * `04. 📖 집사 수칙 노트`: 반려동물 적응 3-3-3 법칙 및 평생 서약 가이드
  * `05. 🗂️ 다이어리 보관함`: 생성된 페이지 영구 보관 및 열람
* **6.3 3단 원클릭 액션 바**:
  * **📋 글 복사하기**: 클립보드 원클릭 복사로 SNS 업로드 지원
  * **🐾 디스코드로 바로 쏘기**: 디스코드 채널로 실시간 다이어리 웹훅 전송
  * **🎬 유튜브 더보기**: 해당 아이의 품종 및 키워드 기반 유튜브 검색 자동 인코딩 연결
* **6.4 다꾸 무드 최적화 UI**: 테마 토글 버튼, 마스킹 테이프 데코, 줄노트 텍스처, 모바일 반응형 탭
* **6.5 실패 및 예외 처리 UX**:
  * **필수값 검증**: 이름 미입력 시 전송 차단 및 안내
  * **로딩 처리**: 생성 대기 시 다이어리 스피너 및 진행 문구 노출
  * **인코딩 안정화**: UTF-8 바이트 보정 및 유니코드 안전 정규식으로 이모지 깨짐 방지

## 7. 타겟 사용자 및 니즈 분석

## 9. 기술 아키텍처 및 디렉터리 구조

### 9.1 시스템 기술 스택
* **Frontend**: HTML5, Vanilla JavaScript (SPA), CSS3 (Flexbox/Grid, Responsive)
* **Backend**: Vercel Serverless Functions (`Python 3.9+`)
* **AI Engine**: Google Gemini API (`gemini-3.6-flash`)
* **Deployment & CI/CD**: GitHub, Vercel
* **Typography**: Google Fonts (Gamja Flower, Gaegu, Nanum Pen Script, Pretendard)

## 10. UX 및 데이터 처리 흐름

```plaintext
1. [아이 정보 입력] ────► 2. [app.js 유효성 검사] ────► 3. [fetch('/api/chat', POST)]
                                                                    │
                                                                    ▼
6. [3단 액션 & 영구 보관] ◄── 5. [ui.js 다꾸 파싱/렌더] ◄── 4. [chat.py + Gemini API]
```

* **1~2단계**: 사용자가 아이의 이름, 품종, 사연을 입력하고 발행 버튼을 누르면 자바스크립트가 유효성을 검증하고 로딩 상태로 전환합니다.
* **3~4단계**: `api/chat.py`로 비동기 POST 요청이 전달되고, `prompts.py`의 다꾸 프롬프트와 결합된 후 Google Gemini AI(`gemini-3.6-flash`)를 통해 UTF-8 안전 바이트 스트림으로 감성 텍스트를 응답받습니다.
* **5~6단계**: `ui.js`가 응답 데이터를 줄노트, 스티커 제목, 손편지 메모 박스로 정밀 파싱하여 화면에 표시하고, 사용자는 즉시 클립보드 복사, 디스코드 전송, 유튜브 검색, 영구 보관 기능을 사용할 수 있습니다.

## 11. 향후 확장 계획 (Roadmap)
* **11.1 다이어리 이미지 다운로드 (Card Capture)**: html2canvas 등을 연동하여 완성된 다꾸 페이지를 인스타그램 피드/스토리 규격의 이미지(PNG)로 저장하는 기능 지원
* **11.2 전국 입양 공고 데이터 자동 크롤링 연동**: 동물보호관리시스템(APMS)의 공공 API와 연동해 유기동물 공고를 원클릭으로 불러와 다이어리로 자동 변환
* **11.3 온·오프라인 임시보호 일지 공유방**: 임시보호 부모들이 아이의 일상을 정기적으로 업데이트하고 공유할 수 있는 열린 아카이빙 피드 개설
